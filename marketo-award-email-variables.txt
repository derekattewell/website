MARKETO EMAIL 2.0 TEMPLATE VARIABLES
=====================================

Add these variable declarations to your template in Marketo:

STRING VARIABLES:
-----------------
{{my.emailSubject}} = "Congratulations on Your Champion Award!"
{{my.ctaURL}} = "https://www.softwarereviews.com/claim-award"
{{my.productCount}} = "3"
{{my.categoryCount}} = "4"

TOKEN USAGE:
-----------------
{{company.name}} - Company Name (Marketo Lead Token)
{{lead.firstName}} - Lead First Name
{{lead.lastName}} - Lead Last Name
{{system.unsubscribeLink}} - Marketo Unsubscribe Link


EDITABLE REGIONS (mktoText):
-----------------
#preheaderText - Preview text
#companyName - Company name heading
#statusHeading - "Champion Status" heading
#heroDescription - Hero description paragraph
#awardsSummary - Awards summary text
#championCount - Champion award count
#leaderCount - Leader award count
#secondaryCount - Secondary award count
#heroCTA - Hero CTA button
#shareHeading - "Share Your Accomplishment" heading
#feature1 - Feature 1 content
#feature2 - Feature 2 content
#feature3 - Feature 3 content
#footerHeading - Footer heading
#footerDescription - Footer description
#footerFinalText - Footer final text
#footerCTA - Footer CTA button
#footerText - Copyright footer

EDITABLE IMAGES (mktoImg):
-----------------
#leftLogo - Info-Tech logo (top left)
#rightLogo - SoftwareReviews logo (top right)
#awardBadge - Award badge trophy image
#icon1 - Feature icon 1 (hexagon)
#icon2 - Feature icon 2 (hexagon)
#icon3 - Feature icon 3 (hexagon)
#footerLogo - Info-Tech logo in footer


CUSTOMIZATION NOTES:
-----------------
1. Replace placeholder images with actual assets
2. Update gradient colors if needed (currently blue gradient)
3. CTA button color is teal (#00C9A7)
4. Maximum width: 600px
5. Fully responsive for mobile devices
6. Outlook-compatible with VML backgrounds
